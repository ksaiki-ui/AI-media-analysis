## 1. 2本の違い

| | 無料メディア改善診断 | 無料参入診断 |
|---|---|---|
| 対象 | オウンドメディアを**運用中**（目安: 記事30本以上、ランクインKWあり） | **未開設**、または**止まっている**（ランクインKWが少ない） |
| 相手の問い | 「うちのメディア、何が足りない？」 | 「そもそもやる意味ある？どこから始める？」 |
| 主役 | 自社 vs 同業のテーマ地図と**伸びしろ** | 同業が記事で得ている**流入・広告換算額・問い合わせ換算**と、**最初の8キーワード** |
| 処方の深さ | 方向性3つまで（記事ごとの指示は面談で） | 最初のテーマと8KWまで提示（全37本のリストは面談で） |
| 面談で渡すもの | GSC連携の精密版／記事ごとの改善シート／比較検討テーマの記事案3本 | 全KWリスト／サンプル記事1本／ナレッジの棚卸し |
| 本体への接続 | 「リライトも含む」「週次のテーマ提案」 | 「月5本なら Wave 1 は2ヶ月で終わる」「自社にしか書けない記事」 |

### 処方をどこまで出すか（前回からの方針変更）
前回は「現状分析のみ、処方は面談で」としていた。参入診断では**スタートKWまで出す**方針に変える。理由:
- 未開設の会社にとっては「どこから始めればいいか分からない」ことが止まっている原因そのもの（資料p.8「ネタが尽きる」「何を書けば問い合わせにつながるのか分からない」）。そこに答えないと、レポートとして価値がない
- 8本を渡しても、**実際に書く手段がない**ことに変わりはない。むしろ「この8本、誰が書くの？」がAIメディアくんへの自然な導線になる
- 出しすぎを防ぐため、**最初の8本だけ**。Wave 2・3のKWは面談で渡す

改善診断は「改善」を名乗る以上、方向性は出す。ただし記事単位の指示（どの記事をどう直すか）は面談で渡す。

## 2. 振り分けロジック

LPで入口を2つに分けたうえで、**自己申告と実データがずれたら実データで補正**する。

```
LP:「メディアを運用中の方 → 改善診断」「これから始める／止まっている方 → 参入診断」
        │
        ▼
解析URLのランクインKW（メディア領域・指名除外・20位以内）を取得
        │
        ├─ 30語以上 かつ 記事30本以上 ──▶ 改善診断
        ├─ それ未満 ──────────────────▶ 参入診断
        └─ 自己申告とずれた場合 ────────▶ 実データ側で生成し、冒頭に一言添える
              例:「運用中とのことでしたが、検索での表示がまだ少ないため、
                  参入診断の形式でお届けします」
```

**止まっているが過去記事で流入がある会社**（例: 記事60本、2年前から更新なし、ランクインKW 80語）は改善診断に振り分ける。これは「止まっている」の典型で、改善診断の「更新率」「検索に出ていない記事」のページが最も刺さる層。

### フォーム項目の差分
| 項目 | 改善診断 | 参入診断 |
|---|---|---|
| 解析URL | メディアのURL（/column/ 等） | コーポレートサイトのURL |
| 主なサービス（1行） | 任意 | **必須**：競合とKWを特定する起点になる（自社KWがほぼ無いため） |
| 比較したい競合（最大3） | 任意 | 任意 |

## 3. 数値の算出ロジック

| 指標 | 式 | 表示ルール |
|---|---|---|
| 推定セッション | Σ 検索数 × CTR(順位)（1位35%／2位19%／3位12%…10位1.5%） | 丸め＋幅（×0.6〜×1.5）。比較を主役にする |
| **広告換算額** | Σ 推定クリック数 × CPC（KWごと） | 「同じ流入を検索広告で買った場合」と必ず説明する |
| **問い合わせ換算** | 推定セッション × 仮定CVR（0.1〜0.3%） | **必ずレンジ＋「仮定値」表記**。単一の数字で出さない |
| 月5,000到達期間 | 検索データの履歴（月次の推定流入）から、開始月→5,000到達月 | 参入診断のみ。「成果までの時間」の実例として使う |
| 難易度 | 上位10ページの被リンク強度から0〜100 | 自社ドメインで狙える上限を併記（例: 30以下） |
| 5位になった場合の増分 | 検索数 × (CTR(5位) − CTR(現在順位)) | 改善診断の「惜しいKW」 |

### 「推定CV」の扱い（最も突っ込まれる数字）
- 単独で出すと「その0.3%の根拠は？」で崩れる。**広告換算額を主、問い合わせ換算を従**にする。広告換算は「CPC×クリック数」で計算方法が明快なため、根拠を説明しやすい
- CVR仮定値は業種別に持てるようにする（`industry_cvr` テーブル）。初期値は0.1〜0.3%とし、**AIメディアくん導入企業の実績が溜まったら置き換える**
- 面談で「御社の実際の問い合わせ率は？」と聞けば、精度を上げつつ会話のきっかけにもなる

## 4. 参入診断：スタートKWの選定ロジック

資料p.14のメディアプランニングの採点軸（商用価値・実現可能性・AI検索での機会）と揃える。**診断で使ったスコアを、受注後のプランニングの初期値にそのまま引き継ぐ**ため。

```
候補KW = 競合3社のランクインKW ∪ サービス説明から展開したシードKWの関連語
スコア = 需要 × 商用価値 × 実現可能性 × 一次情報の一致

  需要         : log(検索数)
  商用価値     : 検索意図（今すぐ依頼 1.0 / 比較検討 0.8 / 知りたい 0.5）× CPCの相対値
  実現可能性   : 難易度 ≤ 自社の上限 なら 1.0、超えるほど減衰
                 ＋ 競合3社の上位占有が少ないほど加点（空白・手薄テーマ）
  一次情報の一致: 御社サイトの事業情報（取扱品目・実績・設備）とKWの関連度（LLM判定, 0〜1）
```

- 上位のKWを**テーマ単位でまとめ、1テーマ8本**を Wave 1 として提示する（記事の塊で評価を集めるため）
- 「いまは狙わないKW」も必ず出す。**狙わない理由を示すことが、選定の信頼性を上げる**
- Wave 2・3 は同じスコアで難易度の上限を段階的に上げて作る（レポートでは概要のみ）

### 注意
- 難易度の上限（30以下など）は仮置き。**Phase 0 で実際に新規ドメインが何ヶ月でどの難易度まで取れたか**を自社メディア（組織の右腕ジャーナル）で検証して決める
- 「一次情報の一致」はサイト掲載情報しか見られない。面談の「ナレッジの棚卸し」で補完する前提

## 7. 決めてほしいこと

1. **問い合わせ換算を載せるか**: 載せるなら仮定CVRの初期値（0.1〜0.3%）でよいか。自社メディアや既存顧客の実績値はあるか
2. **参入診断で8KWまで出すことの是非**: 「これで自分たちで書ける」と思われるリスクを許容するか（私の見立てでは、書く手段がない層なので許容してよい）
3. **LPの入口**: 2つの診断を1つのLPで並べるか、別LPにするか（広告の訴求を分けるなら別LP）
4. **難易度の上限値**: 自社メディア（組織の右腕ジャーナル）の立ち上がりデータを検証に使えるか
