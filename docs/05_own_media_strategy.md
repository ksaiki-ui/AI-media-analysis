# 自社メディア（実績づくり）── 狙う領域とM&A候補の検討

作成日: 2026-10-05 / 対象: AIメディアくんの実績づくりを兼ねた、MIRAIKU自社メディアの買収または立ち上げ

> 表記: 【事実】は出典で確認したもの、【仮定】は試算のための置き値、【推測】は判断です。
> 試算の数値はすべて【仮定】に基づくレンジです。実行前に、候補KWの実測（キーワードプランナー、Ahrefs、AIメディアくんの参入診断）で置き換えてください。

---

## 0. 結論（先に）

1. **最初に決めるべきは領域ではなく「何の実績か」**。AIメディアくんの買い手は「月5万円を払う中小BtoB企業」。彼らに効くのは **PVの大きさではなく「問い合わせ件数とCPL（1件あたり獲得コスト）」**。BtoCアフィリエイトの大PVは「アフィリエイターの数字で、うちには関係ない」と受け取られやすい。
2. **本命: 1業種に絞った「中小事業者向け経営メディア」**（候補: 介護事業所 ／ 工務店・建設 ／ 治療院）。読者（中小の事業者）が **MIRAIKUのコンサルの見込み客であり、AIメディアくんの見込み客でもある**。収益は「業務SaaSの資料請求（4千〜1.2万円）＋求人送客＋MIRAIKUへの問い合わせ」の3本立て。PVは小さいがCVの単価が高い。
3. **対抗: 地域×生活サービスのDB型メディア**（例: 市区町村別の粗大ごみ・不用品回収ガイド、住宅設備×自治体補助金）。AI Overviewが出にくい地域型の検索で、送客単価も高い。**PV・収益の絶対額と、AIメディアくんの「DB型」機能の実証**を担う。
4. **買い方は「安い停滞サイト（5〜80万円）」を基本にする**。収益の出ているサイトを15〜20倍で買うと、伸びたのがAIのおかげか元からかを説明できない。「導入前は横ばい→導入後に伸びた」のほうが、事例として説明できる。
5. 「組織の右腕ジャーナル」（運用中の自社BtoBメディア）がすでにある。**新しいメディアは、右腕ジャーナルでは示せない実績（業種特化のCV、DB型、収益）を取りに行く**位置づけにする。右腕ジャーナルの現状の数字を先に確認したい。

## 1. 前提の問い直し

### 1.1 「BtoCアフィリエイト」と「AIメディアくんをBtoBに売る」は両立するか

| 観点 | BtoCアフィリエイト（大PV） | 業種特化BtoB（小PV・高単価CV） |
|---|---|---|
| 実績の見栄え | ◎ 「月10万PV」は目立つ | △ 「月1.5万PV」は小さく見える |
| 中小企業の社長への説得力 | △ 自社の問い合わせが増える話に変換できない | ◎ 「月20件の資料請求、CPL 2,500円（広告の1/4〜1/6）」 |
| 他社の事例との差 | ✕ EmmaToolsにすでに「PV 5,000→18万」の事例があり、CVが伸びなかったことも公開されている | ○ AI記事ツールの事例はPV・工数の数字が中心で、CPLまで出している例は少ない |
| 収益の立ち上がり | 遅い（物販1〜10%、送客は数千円） | 早い（1件2,000〜15,000円） |
| Googleのリスク | 大量生成コンテンツの不正使用ポリシーの対象になりやすい | ある。ただし一次情報（自社の支援知見）を入れやすい |
| 本業へのつながり | ほぼない | コンサルの見込み客を直接集められる |

【事実】
- BtoB企業の実際のCPAは「1万〜1.5万円」が最も多い（IDEATECH、2024年、n=100。https://prtimes.jp/main/html/rd/p/000000237.000045863.html）。
- EmmaToolsの事例: ニューズドテックで月間PV 5,000→18万（約4ヶ月）。ただし「CVは期待ほど伸びなかった」（https://emma.tools/magazine/interview-newsedtech/）。

【推測】AIメディアくんのLPの主張は「渡す情報（自社ナレッジ）で品質が80→92に上がる」こと。**ナレッジを持っていない領域のアフィリエイトサイトでは、この主張を自分で証明できない**。MIRAIKUが知見を持っている領域を選ぶことが、プロダクトの主張と一致する条件になる。

### 1.2 「買う」ことの是非

| | 買収 | 0から立ち上げ |
|---|---|---|
| 時間 | ドメインの年齢・被リンク・インデックスを買える。新規ドメインの立ち上がり（目安6〜12ヶ月）を短縮 | 遅い |
| 事例としての説明しやすさ | 収益サイトを買うと「元から伸びていた」と区別できない | 0→Nで最も説明しやすい |
| リスク | 数字の水増し、過去のペナルティ、ASPアカウントを引き継げない | 伸びないリスク |

→ **「インデックスとドメイン年齢はあるが、更新が止まって横ばい・下降しているサイト」を安く買う**のが、時間と説明しやすさの両方を取れる。
【事実】ラッコM&Aでは、利益ゼロ・赤字のサイトの約7割が5〜30万円で成約している（成約1,050件の分析。https://rakko.inc/news/analysis-1050/）。

## 3. 候補領域の評価

### 3.1 2026年の検索環境で、何が残っているか

【事実】
- AI Overviewの表示率はクエリの型によって大きく違う（Ahrefs、2026年4月。二次引用 https://0120.co.jp/blog/aio-125/）: 定義型（〇〇とは）87%、比較型78%、料金型74%、おすすめ型45%、購入系8%、地域型5%。
- AI Overviewが出ると、検索1位のクリック率が約38%下がる（Ahrefs、2025年12月、日本。https://www.commercepick.com/archives/86565）。
- 2026年3月・5月のコアアップデートで、ページ数の多いDB型サイトのインデックスが減り、表示実績のないページが外される動きが強まった（https://webanalytics.speee.jp/media/article/google-core-updates/）。

【推測】残っている余地は次のとおり。
- **地域×施設・業者**の検索
- **料金・制度・相場など、変わり続ける一次データ**
- **送客・見積もり・資料請求など、AIの回答では完結しない成果地点**
- 逆に「〇〇とは」「AとBの違い」型の解説記事は、AI Overviewに置き換えられる前提で考える。
- DB型は「需要のあるページだけをインデックスさせる」設計が必須。1エンティティ1記事を機械的に量産するのは、2026年はむしろ危ない。

**D. 収益の出ているサイトを買う（月利10〜20万円を15〜20倍＝150〜400万円）── 非推奨**
- 収益の絶対額は最も早く立ちますが、AIの成果と区別できません。
- 買った直後のアップデートで下落するリスクを全額負います。
- 23213（育児用品の比較）のように、PVが落ちているのに利益が横ばいの案件は特に注意が必要です。

### 4.3 コスト【仮定】

- AIメディアくんの記事生成の原価（API）は、社内の実績値で置き換えてください。
- 人の工数: 確認 20分×20本＝約7時間／月、ヒアリング・企画 約4時間／月。DB型は初期のデータ整備に40〜80時間。
- 業種特化BtoBは、専門家の監修やインタビュー（月3〜5万円程度）を入れると、一次情報と信頼性の両方が上がります。

## 5. 進め方

### 5.1 領域の選び方（ユーザー案の手順を補強）

ユーザー案「ドメインランクとラッコM&Aを見て、競合のドメインを確認し、その領域の記事を書く」に、次を足すことを提案します。

1. **候補の業種を、MIRAIKUの支援実績から3つ選ぶ**。一次情報（支援先の事例・数字・現場の声）を出せることが、AIメディアくんの主張と一致する条件。
2. **AIメディアくんの「参入診断」を自社に使う**。3業種それぞれで、上位の競合・テーマ地図・最初の8KWを出す。これは参入診断のドッグフーディングにもなる。
3. **隙間の指標は「ドメインランクの平均」ではなく「上位10件のうち弱いサイトが何件あるか」**。DR20未満のサイト、個人ブログ、Q&Aサイト、PDFが上位に混ざっているKWが、勝てるKW。ドメインランクの平均だけを見ると、大手1社に引っ張られて判断を誤ります。
4. ラッコM&Aで、その業種の停滞サイトを毎日ウォッチ。買う基準（下記）に合えば即交渉。なければ新規で立ち上げる。

### 5.2 買う基準（案）

## 6. 確認したいこと（意思決定に必要）

1. **「組織の右腕ジャーナル」の現状**（記事数・PV・問い合わせ数）。これがすでにBtoBの実績になっているなら、新メディアの役割が変わります。
2. **MIRAIKUの支援実績が厚い業種**はどこか。介護・建設・治療院・士業のどれかに一次情報があるか。
3. **コンサル1件の受注単価**。BtoBシナリオのCV1件の価値が、アフィリエイト単価（数千円）より桁違いに大きいなら、評価はさらにBtoBに傾きます。
4. **予算と工数の上限**。買収に出せる金額、月に確認作業へ割ける時間。
5. **実績を「社名を出して公開する」か**。自社運営だと明かすかどうかで、テーマ選び（BtoCのアフィリエイトサイトを自社名で出せるか）が変わります。
