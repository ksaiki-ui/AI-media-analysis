# フリーコンサル集客メディアと、サイトストック案件（id=122120）の評価

作成日: 2026-10-06 / 前提: [07_standalone_niches.md](./07_standalone_niches.md)

> 表記: 【事実】出典あり、【仮定】試算のための置き値、【推測】判断。

---

## 0. 結論

1. **サイトストックの案件（id=122120）は、今の情報のままなら買うべきではありません。** 価格が月間利益のわずか2.7ヶ月分で、相場の約7分の1です。検証されていない数字が並んでいます。直接取引です。ただ、数字が本物なら破格なので、**検証にお金をかけずに済む手順（§2.3）で白黒をつけ、エスクローと分割払いで守る**なら検討の余地は残ります。
2. **フリーコンサル集客は、1件あたりの価値が大きく変わったため有力**になりました。月の粗利20〜30万円 × 稼働期間で、1人の稼働開始は100万円単位の価値になります。
3. ただし、**対象を「100%稼働できる人」に変えると、前回見つけた隙間（診断士・副業層）から、競合の多い市場（ファーム出身・PMO層）に戻ります。** 大きなKW（「フリーコンサル エージェント おすすめ」等）で新規ドメインが勝つのは難しい、という懸念は正しいと考えます。
4. 勝ち筋は**「PVを追わず、登録数を追う」**ことです。
   - 体験談でしか書けないロングテールのKWを狙う。
   - 実名の著者として発信する（X、note、LinkedIn）。
   - SEO以外の経路（人づて、スカウト、アフィリエイト広告の出稿）も併用する。
   - 1人の価値が100万円単位なら、**月数千PVでも事業として成立**します。
5. **ドメインパワーを買って方向転換するのは、勧めません。** Googleの「期限切れドメインの不正使用」ポリシーの対象になりえます。近い分野（コンサル転職・ハイクラス転職）のサイトに限れば可能ですが、今は該当する売り案件がありません。

## 1. フリーコンサル集客の経済性

### 1.1 1人あたりの価値【仮定：ユーザーの提示値から計算】

| 項目 | 値 |
|---|---|
| 案件単価 | 月150万〜200万円 |
| MIRAIKUの粗利 | 月20万〜30万円／件 |
| 平均稼働期間 | 6ヶ月と仮定（要確認） |
| **1人の稼働開始あたりの粗利** | **120万〜180万円（中央値150万円）** |
| 登録から稼働開始に至る割合 | 2〜5%と仮定 |
| **登録1件あたりの価値** | **3万〜7.5万円** |

【事実】比較のため、競合エージェントがアフィリエイトに払っている単価は、面談1件あたり1万〜2.6万円です（フリーコンサルタント.jp 26,000円、フリーコンサルBiz 22,000円、プロフェッショナルハブ 23,000円など。affisearch.com）。
→ **MIRAIKUの登録1件の価値は、競合が払っている獲得単価を上回る可能性があります。** SEOだけに頼らず、MIRAIKU自身がASPに広告を出して、アフィリエイターに集めてもらうという選択肢も成り立ちます。

### 1.2 前提として確認すべきこと
- **150万〜200万円の案件を、継続的に何件出せるか**。登録者が増えても、案件がなければ粗利になりません。逆に案件が月1件しかないなら、必要な登録者は月20〜50人程度で足ります。
- **契約の形**。MIRAIKUがクライアントから受けた案件を、フリーランスに再委託する形なら、職業紹介の許可は不要です。ただし、クライアントがフリーランスに直接指示を出す運用になると、偽装請負とみなされるおそれがあります。契約と運用の設計を、弁護士・社労士に確認してください。

### 1.3 対象層の変化と競合

| | 前回の想定 | 今回 |
|---|---|---|
| 対象 | 中小企業診断士・事業会社出身者・顧問層（週1〜3日） | 100%稼働できるフリーコンサル（ファーム出身、PMO、事業会社） |
| 案件単価 | 月50万円 | 月150万〜200万円 |
| 競合 | 受験校と量産サイト。エージェントとはあまり重ならない | **ハイパフォコンサル（登録5.7万人）、フリーコンサルタント.jp（2.75万人）、ProConnectなどの上場企業・大手と、そのアフィリエイター**が正面の競合 |
| 検索量 | 診断士の副業・独立 1,000〜3,500 | フリーコンサル 800、フリーコンサル 案件 168、エージェント おすすめ 56 |

【推測】
- 「フリーコンサル」系のKWは、検索量が小さいうえに、アフィリエイトの報酬単価が高いため、比較記事が密集しています。**大きなKWを新規ドメインで取りに行くのは非効率**です。
- 一方で、検索量の小ささは、この事業では弱点になりません。必要なのは月に数人の稼働開始で、そのために要る登録者は数十人規模だからです。

## 2. 新規ドメインで伸ばせるか

### 2.1 一次体験コンテンツは、どこで効くか【推測】

効くのは、**比較記事が答えていない、当事者の悩み**です。
- 例: 「フリーコンサル 1年目 収入」「案件が途切れる」「契約トラブル」「単価交渉」「法人化のタイミング」「インボイス」「エージェントのマージン」「ファームに戻るか」「40代 独立 失敗」
- これらは、検索量が小さく、AI Overviewが一般論でまとめにくく、エージェントの比較記事とも競合しにくいKWです。
- 2026年3月・5月のコアアップデートでは、独自性（Information Gain）が重視されました（https://webanalytics.speee.jp/media/article/google-core-updates/）。実名の著者が具体的な数字を出す体験記事は、この流れに合います。

効かないのは、次のKWです。
- 「フリーコンサル エージェント おすすめ」「比較」「ランキング」
- 比較サイトとエージェント公式が上位を固めていて、体験談だけでは順位を動かしにくい。

### 2.2 推奨する設計

| 項目 | 設計 |
|---|---|
| 場所 | MIRAIKUのドメイン（ドメインの評価があれば）、または新規ドメインに実名の著者ページを置く |
| 柱1: 独立のリアル | ユーザー自身の独立・フリーランス体験。収入の推移、案件の取り方、失敗談 |
| 柱2: 案件の実例 | MIRAIKUが扱う案件の業務内容・単価帯・稼働条件（守秘の範囲で） |
| 柱3: 稼働者のインタビュー | MIRAIKUの案件に参画したフリーランスの体験談（月1〜2本） |
| 柱4: 実務Q&A | 契約、税金、インボイス、法人化、単価交渉 |
| 外部の発信 | ユーザー本人のX、note、LinkedInで同じ一次情報を発信し、サイトに誘導 |
| CV | 「案件の相談・登録」（30分の面談）。合わない人には、副次的に他社エージェントを紹介（アフィリエイト） |
| KPI | PVではなく、**登録数・面談数・稼働開始数** |

### 2.3 試算（12ヶ月時点）【仮定】

| | 低 | 中 | 高 |
|---|---|---|---|
| 月間PV | 0.3万 | 0.8万 | 2万 |
| 登録率（÷PV） | 0.3% | 0.5% | 0.7% |
| 登録／月 | 9人 | 40人 | 140人 |
| 稼働開始率 | 2% | 3% | 5% |
| 稼働開始／月 | 0.2人 | 1.2人 | 7人（※案件数が上限） |
| 稼働開始の粗利の総額（1人150万円） | 27万円 | 180万円 | 1,050万円 |
| ＋他社エージェントへの紹介（1.5万円×承認50%×PVの0.05%。合わない人だけに出す副次導線） | 1.1万円 | 3万円 | 7.5万円 |

- 「中」で、12ヶ月目の1ヶ月分だけで将来粗利180万円です。高シナリオは、MIRAIKUの案件数を超えるので現実的ではありません。
- **最大の不確実性はPVではなく、「登録した人のうち、100%稼働できて、案件に合う人の割合」**です。最初の3ヶ月で実測してください。

### 2.4 SEO以外の経路も同時に

SEOは、成果が出るまで6〜12ヶ月かかります。1人150万円の価値があるなら、次の経路のほうが早い可能性があります。
- ユーザー本人とMIRAIKUの人脈からの紹介。稼働者に紹介報酬（例: 稼働開始で10万円）を出す。
- LinkedInでの直接スカウト
- ASPに広告主として出稿し、面談1件あたり1.5万〜2.5万円を払う（競合と同じ土俵）
- **メディアは、これらの経路の「信用の裏付け」（運営者の実体と実績を見せる場所）としても機能します。**

## 3. ドメインパワーを買って方向転換する案

【事実】Googleは2024年3月に「期限切れドメインの不正使用」をスパムポリシーに追加しました。評価のあるドメインを買い、元とは関係の薄い内容で順位を得ようとする行為が対象です（https://developers.google.com/search/docs/essentials/spam-policies）。

【推測】
- 全く別のテーマへの転換は、評価が引き継がれないか、ペナルティのリスクがあります。
- 近い分野（コンサル転職、ハイクラス転職、ITフリーランス）への転換なら、リスクは小さいです。ただし、2026年10月時点のラッコM&Aでは、該当する売り案件は見つかっていません。過去の成約例は、コンサル転職ブログ（月4,445PV、150万円）、ITフリーランス情報サイト（月9,000PV、35万円）です。
- **優先度は低いです。** 適した案件が出たらウォッチする程度にとどめ、本筋は自社の一次情報で作ることにします。

## 4. サイトストック案件（id=122120）の評価

### 4.1 掲載内容【事実：https://sitestock.jp/sales_web_detail.html?id=122120 、2026-10-06取得】

| 項目 | 内容 |
|---|---|
| テーマ | 在宅ワーク・副業による資産形成のブログ型メディア |
| 月間PV／UU | 181,900／118,000 |
| ページ数 | 約50ページ |
| 月間売上／営業利益 | 25万円／24.86万円（2026年1月からの平均売上は25.3万円） |
| 収益源 | アフィリエイト、**ポイントサイト**、AdSense |
| 費用 | サーバー費 月1,400円のみ |
| 運営開始 | 2021年3月（ドメイン約5年） |
| SEO対策 | 「なし」 |
| 更新 | 不定期、作業は少なめ |
| 希望価格 | 66万円（税込） |
| 取引形態 | **直接**（仲介なし） |
| 掲載 | 2026年10月5日、閲覧76回、交渉0件、交渉期限は2026年11月 |
| 記載なし | PV・UUの推移、流入元の内訳、検索順位・主要KW、被リンク、記事の作り方 |

### 4.2 疑わしい点

| # | 点 | なぜ問題か |
|---|---|---|
| 1 | **価格が月間利益の2.7ヶ月分** | 相場は平均17.8ヶ月分（ラッコM&A、成約1,050件の分析。https://rakko.inc/news/analysis-1050/ ）。相場どおりなら約440万円。2026年に3〜6倍で成約した例もあるが、いずれも「運営が数ヶ月」「直近だけ急伸」の案件。**5年運営で安定しているとされるサイトが2.7倍**は説明がつかない |
| 2 | **50ページで月18万PV、しかも「SEO対策なし」** | 1ページあたり月3,600PV。「副業」「在宅ワーク」は大手メディアが占める激戦区で、SEOでこの効率は考えにくい。流入元の記載もない。SNS、ポイントサイトからの誘導、または水増しの可能性 |
| 3 | **収益源に「ポイントサイト」** | ポイントサイトの紹介報酬は、売り手個人の会員アカウントに紐づくのが一般的で、**譲渡で引き継げない**可能性が高い。ASPのアカウントも引き継げず、買い手側で審査し直しになる（特別単価も消える） |
| 4 | **直接取引** | サイトストックでは、直接取引の案件は情報の真偽確認が行われていないのが一般的とされる（https://ma-window.co.jp/sitestock-hyoban/ ）。サイト売買では、数字を偽って売りつける詐欺の事例がある（https://rakkoma.com/knowledge/1553/ ） |
| 5 | **推移データがない** | 売上の「1月からの平均」だけで、月次の推移・PVの推移が出ていない |
| 6 | テーマの性質 | 「資産形成」はお金に関わるYMYL寄りの領域で、2025年12月以降のコアアップデートで変動が大きい |
| 7 | 目的との一致 | 読者は「在宅ワーク・ポイ活」層とみられる。**100%稼働のフリーコンサルの集客には転用しにくい** |

【推測】考えられるのは次の3つです。
- (a) 数字が虚偽
- (b) 数字は本物だが、収益が売り手個人に紐づいていて引き継げない
- (c) 売り手が相場を知らない本物の掘り出し物

(c)の確率は低いと見ます。ただ、(c)なら66万円で月20万円超が残る破格の案件なので、**安く白黒をつける手順**を踏む価値はあります。

### 4.3 交渉に進む場合の手順と中止の条件

**Step 1: 交渉申込の前（無料、30分）**
- URLの開示を求め、次を確認する。
  - Googleで `site:ドメイン` を検索し、インデックス数を見る
  - Ahrefsなどで推定の自然検索流入と被リンクを見る
  - Wayback Machineで過去の中身を見る
- **中止の条件**: 推定の自然検索流入が、申告PVの1割未満なのに、流入元の説明がない場合

**Step 2: データの直接確認（画面共有）**
- GA4: 直近24ヶ月の月別PV、流入元の内訳（自然検索／SNS／参照元／直接）
- Search Console: 主要クエリと順位、手動対策の有無
- ASP・ポイントサイト・AdSenseの管理画面: 月別の発生と確定、**どの案件・どのアカウントで発生しているか**
- **中止の条件**:
  - 画面共有を拒まれる
  - 収益の過半がポイントサイトの紹介報酬
  - 流入の過半が、引き継げない経路（売り手のSNS、メルマガ等）

**Step 3: 契約と支払い**
- サイトストックのエスクロー（または仲介プラン）を使う。直接振り込みはしない。
- **分割払い**（例: 譲渡時に20万円、2ヶ月後に売上が申告の8割以上なら残り46万円）
- 表明保証（申告数字が正しいこと）と、競業避止

**Step 4: 買った後**
- ASPには買い手のアカウントで登録し直し、案件を張り替える。張り替えの間は収益が落ちる前提で考える。

## 5. 推奨

1. **フリーコンサル集客を本命にします。** 体験コンテンツ×実名の発信×登録数のKPIで設計し、SEO以外の経路（紹介・スカウト・アフィリエイト出稿）も併用します。
2. **サイトストックの案件は、§4.3のStep 1〜2で白黒をつけます。** 費用はかからないので、やる価値はあります。中止の条件に1つでも当たれば見送ります。買う場合も、フリーコンサル用ではなく、**独立した副業メディアとしての収益資産**と位置づけます。
3. ドメインを買って方向転換する案は、優先度を下げます。

## 6. 確認したいこと
1. 150万〜200万円の案件は、今、月に何件出せますか。平均の稼働期間はどれくらいですか。
2. ご自身が、実名（または顔の見える筆名）で発信することは可能ですか。体験コンテンツの効果は、著者の実在性で大きく変わります。
3. MIRAIKUのドメインに、検索の評価（運営年数、被リンク）はありますか。
