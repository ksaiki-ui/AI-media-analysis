# メディア解析レポート無料プレゼント施策 ── マーケティング戦略・競合分析

作成日: 2026-09-27 / 対象: AIメディアくん（株式会社MIRAIKU）ローンチ後のリード獲得施策

> 前提資料: 「AIメディアくん サービス紹介資料 v1」（34p）。
> アプリ（`d1tdolsilcuyro.cloudfront.net/#kwlab`、`127.0.0.1:8787/#kwlab`）は作業環境から到達できず未確認。
> **kwlab（キーワードラボ）の既存ロジック・データソースを再利用できるかは要確認**（→ 末尾「確認したいこと」）。

---

## 0. 結論（先に）

1. **施策自体は筋が良い**。AIメディアくんの初回商談（資料p.34「狙えるキーワードを具体的に提示」）を**前倒しで自動化したもの**であり、商談の中身と地続きになる。
2. ただし **「URLを入れると競合比較レポートが届く」は既に差別化にならない**。ferret（ベーシック）が「自社＋競合2社をAIが10ページで比較、メール送付」をほぼ同じ形で提供済み。無料・登録不要の即時診断ツールも複数ある。
3. 差別化は「診断の網羅性」ではなく、**AIメディアくんの思想（テーマ＝クラスター単位の戦略、自社にしか書けない領域）をレポートの“見え方”そのものにすること**。具体的には
   - 単語の順位表ではなく **「どのテーマで誰が勝っているか」のクラスター地図**
   - 各社の **メディア戦略タイプの言語化**（例: 用語集型／比較検討型／事例型）
   - 自社が取れていないテーマの **機会の大きさ（推定セッション）だけを示し、「何を書くか」は面談で出す**
4. 最大の設計上の論点は3つ。**(a) メディアを持っていない／小さい会社でもレポートが成立するか**、**(b) 推定値の精度と信頼**、**(c) 他社ドメインを入れて競合情報を抜かれる悪用**。いずれも仕様で手当てする（下記）。
5. 作り込む前に **手作業で10〜20件出して面談化率を測る（Phase 0）** ことを強く推奨。自動化の価値は「面談化率が高い」ことが確認されて初めて生まれる。

## 1. 施策の位置づけ

### 1.1 AIメディアくんのターゲットと、この施策が刺さる層

資料から読み取れるターゲット:「BtoB」「マーケ担当が兼務」「予算が限られる」「ナレッジはある」「メディアが続かない／始められない」。

ここで**ユーザー案とのズレ**を指摘したい。

| 層 | 状態 | 自社メディアの解析結果 | 施策との相性 |
|---|---|---|---|
| A. 運用中・伸び悩み | 記事50本以上、更新停滞 | 意味のある数字が出る | ◎ 現状分析がそのまま刺さる |
| B. 始めたが止まった | 記事10〜50本 | ランクインKWが数十程度、スカスカ | △ 自社部分が貧弱で「で？」となる |
| C. 未開設（コーポレートサイトのみ） | 記事0 | **ほぼ空** | ✕ 現状案だとレポートが成立しない |

資料の訴求（「続かない」「書ける人がいない」「ネタが尽きる」）は **B・C層の課題**。つまり **本来の主要顧客ほど、「自社メディア解析」の価値が薄い**。

→ **対策**: レポートを2モードにする（詳細は仕様書）。
- **現状解析モード**（A層）: ユーザー案どおり、自社 vs 競合の現状分析
- **参入診断モード**（B・C層、自社ランクインKWが閾値未満で自動切替）: 「競合がどのテーマで、どれだけ集客しているか」＝**市場地図**を主役にし、自社は「まだ取れていない総量」として描く

C層にとっては「同業がオウンドメディアで月◯万セッション取っている」という事実自体が最大の動機付けになる。こちらの方がむしろ商談化しやすい可能性がある。

### 1.2 「改善指示より現状分析」について

方針には賛成。理由は、改善策まで渡すと (1) それで満足されて面談理由が消える、(2) 汎用的な改善策は他社の無料診断と同質化する、(3) 自動生成の改善提案は外すと信用を失う、から。

ただし **純粋な現状分析だけだと「へえ」で終わるリスク**がある。行動を起こさせるには「差分の大きさ」が要る。

→ 提案: **「現状」＋「機会の大きさ（数字）」まで出し、「何を・どう書くか」は出さない**。
- 出す: 「競合3社は『◯◯』テーマで合計 推定月1.2万セッション。御社は0」
- 出さない: 「だから『◯◯とは』『◯◯ 比較』を書け」
- 面談で出す: 書ける記事テーマ3案（＝資料p.17の「毎週3案」の体験版）、GSC連携での精密版

### 1.3 ファネル設計

```
LPトップ / 資料DL後サンクス / フォーム文面 / 広告
        │
        ▼
 申込フォーム（URL + 会社名・氏名・メール・電話）
        │  └ 悪用・非対象フィルタ（後述）
        ▼
 レポート生成（MVPは人のQA付き、1営業日以内）
        │
        ▼
 メール送付（Web閲覧リンク＋PDF）── 開封・閲覧ページをトラッキング
        │
        ▼
 閲覧後24h以内に架電（「数字の読み方を30分で解説します」）
        │
        ▼
 面談（30分）: 精密版（GSC連携）＋ 書ける記事テーマ3案を提示
        │
        ▼
 サンプル記事1本生成（資料p.34 STEP3）→ 受注
```

**ポイント**
- **PDF添付だけで送らない**。Webビューワーのリンクで送れば「開いたか」「どのページを見たか」が分かり、**架電のタイミングと話題**が決まる。PDFは同ページからDL可能にする。
- 架電の口実を「営業」ではなく「**推定値の読み方の解説**」にする。推定値には必ず注記が要る（精度の限界）ので、それ自体が自然な接点になる。
- **LINEについて**: BtoBの決裁者層との継続接点としては、メール＋電話の方が標準。LINEは「レポート完成通知」「解説動画配信」用の**任意の補助導線**とし、必須にしない（入力項目を増やすと申込率が落ちる）。ターゲットが中小・経営者直で、LINE常用層が多いなら検証の価値はある。→ Phase 1でA/Bテスト対象。

### 1.4 フォーム項目

| 項目 | 必須 | 理由・懸念 |
|---|---|---|
| 解析対象URL | ◎ | ドメイン単位で解析（サブディレクトリ型メディアはパスも許容） |
| 会社名 | ◎ | |
| 氏名 | ◎ | |
| 会社メールアドレス | ◎ | **フリーメール不可**。メールドメインと解析ドメインの一致をチェック（悪用対策） |
| 電話番号 | ◎ | 架電前提なら必須。ただし離脱要因。**「解説のお電話をする場合があります」と明記**して期待値を合わせる |
| 比較したい競合URL（最大3） | 任意 | 自動選定の外れを防ぐ。空欄なら自動選定 |
| 目的（問い合わせ増／採用／認知） | 任意・選択式 | 面談の準備用。1クリックで済む形に |
| 営業連絡・メルマガ同意 | ◎ | 特定電子メール法・個人情報の同意 |

「URLを貼るだけ」の体験とトレードオフになるので、**URL入力 → 次画面で連絡先** の2ステップにし、1ステップ目で心理的コミットを取る（URL入力だけで「解析を予約しました」と表示）ことを推奨。

### 1.5 悪用・非対象への対策（ここは必須）

この施策は **任意の他社ドメインの競合分析を無料で取得できる仕組み** になりうる。
- SEO会社・制作会社が顧客提案用に使う
- 競合が自社（MIRAIKU）のノウハウ確認に使う
- 第三者のドメインについてのレポートを無関係の人に送ることになる

対策:
1. メールドメイン ≠ 解析ドメイン の申込は **自動生成せず人が審査**（代理店は歓迎か除外か、方針を決める）
2. 同一ドメインは30日に1回まで
3. フリーメール不可、Turnstile等のbot対策
4. 支援会社リスト（SEO・広告代理店）ドメインは除外 or 別導線

### 1.6 KPI と収支の仮説

※以下はすべて**仮説値**。Phase 0で実測して置き換えること。

| 段階 | 仮説 | 月間件数（LP 3,000訪問時） |
|---|---|---|
| LP → 申込 | 3% | 90 |
| 有効申込（フィルタ後） | 70% | 63 |
| レポート閲覧 | 80% | 50 |
| 架電接続 | 60% | 30 |
| 面談化 | 有効申込の30% | 19 |
| 受注 | 面談の15% | 約3社 |

受注1社の価値: 月75,000円 × 継続12ヶ月 ＋ 初期ライトパック200,000円 ≒ **110万円**（継続率は未知数）。
→ 月3社で約330万円/コホート。レポート原価（後述: 1件数百円）は無視できる水準で、**ボトルネックはレポート原価ではなく「架電・面談する人の工数」**。月60件の架電と20件の面談を誰が回すのか、を先に決めるべき。

注視すべきKPI（優先順）:
1. **有効申込 → 面談化率**（施策の成否そのもの）
2. レポート閲覧率・閲覧ページ（どのページが効いているか）
3. 面談 → 受注率（レポートで来た人が「本当に買う人」か）

## 2. 競合分析

### 2.1 同じ「無料診断レポート」施策（直接競合）

| 提供者 | 形式 | 競合比較 | 自動/手動 | 特徴 | 示唆 |
|---|---|---|---|---|---|
| **ferret（ベーシック）「AI SEO診断」** | 自社URL＋競合URL（2社まで）をフォーム入力 → **10ページのレポートをメール送付** | ◎ 競合2社と4指標（ドメイン評価・保有KW数・月間流入・参照ドメイン数）で横並び | AI生成 | 「要点3つ」「次に書くべき記事」「優先度つき改善アクション」まで出す | **ほぼ同じ施策が既に存在**。同じ土俵（指標の網羅＋改善提案）では勝てない |
| ランクエスト「SEO無料診断」 | 申込制 | ○ 競合比較・効果シミュレーション | コンサルタント | 流入分析・内部分析・コンテンツチェックまで | 手厚いが納期がかかる／営業色が強い |
| アナライズ（seo-llmo.com）、UMOREN AI、AIOGeoScan 等 | URL入力 → **即時・登録不要** | △ | 全自動 | SEO＋LLMO（AI検索）スコア | **「その場で見られる」が当たり前**になりつつある。1営業日待たせる理由が必要 |
| Trilia、itomakihitode 等 | URL入力 → 即時 | ✕ | 全自動 | 内部SEO項目チェック（60項目等） | テクニカル監査。別物 |

### 2.2 ツール（間接競合: 見込み客が「自分で調べる」選択肢）

| ツール | 月額目安 | 見込み客にとって |
|---|---|---|
| ミエルカSEO | 44,000〜110,000円（税込）、7日間無料 | 競合分析は可能だが、使いこなす人がいない層（＝AIメディアくんのターゲット）には重い |
| Keywordmap / TACT SEO / EmmaTools | 数万円〜 | 同上 |
| Ahrefs / Semrush | $129〜 / $139〜 | 英語UI、日本の中小BtoBには敷居が高い |
| Ubersuggest、ラッコキーワード等（無料枠） | 0円 | 1ドメインずつなら無料で見られる。**「データそのもの」には希少価値がない** |

### 2.3 AI記事生成ツール（本体の競合）

Transcope、SAKUBUN、BringRitera、Catchy 等。多くは「キーワードを入れると記事が出る」起点で、**メディア全体の戦略設計（クラスター単位）から入るものは少ない**。
→ 診断レポートでも **「記事単位」ではなく「テーマ単位」で語る** ことが、そのまま本体の差別化（資料p.14「キーワードを、テーマの塊で管理」）の予告編になる。

### 2.4 差別化ポジション

```
                     改善提案まで出す
                          ▲
       ferret AI SEO診断 ●│● ランクエスト（人手）
                          │
  指標・スコア中心 ◀───────┼───────▶ 戦略・テーマ中心
  (単語/ページ単位)        │         (クラスター/メディア特性)
   即時診断ツール群 ●     │
                          │    ★ AIメディアくん診断（狙う位置）
                          ▼        現状＋機会の大きさ。処方は面談で
                     現状分析のみ
```

**勝ち筋（仮説）**
1. **テーマ地図**: 「御社と競合3社、どのテーマで誰が勝っているか」が1枚で分かる。スコアや項目チェックではなく、経営者が読める“地図”にする
2. **メディア戦略の言語化**: 「A社は用語解説で広く薄く、B社は比較記事で指名前の検討層を刈り取っている」— 人のコンサルが言うような解釈をAIが書く
3. **メディア未保有でも成立**: 参入診断モード。ferret等は自社のサイト評価が軸なので、メディア未保有だと薄い
4. **（Phase 2）AI検索での露出**: AI Overview等での引用状況。資料p.10・p.19の「AI検索に引用される」訴求と直結

**逆に、やらない方がよいこと**
- 内部SEO（表示速度・タグ等）のチェック項目: 同質化するうえ、AIメディアくんの提供価値と関係ない
- 被リンク分析の深掘り: 同上
- スコア（◯点／100点）での総合評価: 刺激はあるが根拠を問われると弱い。数字は「推定セッション」「KW数」など説明可能なものに限る

## 3. リスクと反論

| リスク | 内容 | 手当て |
|---|---|---|
| 推定値の信頼 | サードパーティDBの推定流入は日本語・BtoBロングテールで**実数と大きくずれる**ことがある。GA4を見ている担当者は「全然違う」と感じ、レポート全体の信用が落ちる | 数値はレンジ or「推定」を明記。**絶対値より競合との相対比較を主役に**。面談で「GSC連携した精密版」を提示する（＝架電・面談の口実に転化） |
| 競合の自動選定の外れ | SERP重複ベースで選ぶと、Wikipedia・大手メディア・ポータルが「競合」として出る | 除外リスト＋LLMで事業類似度を判定。ユーザー指定を優先。MVPは人がQA |
| 期待値ズレ | 「無料で改善策がもらえる」と期待した申込者の不満 | LP・フォームで「現状分析レポート」「改善策は解説時にご提案」と明示 |
| 営業リソース不足 | 申込が来ても架電できず放置 → 施策の信用毀損 | 月の上限件数を設定（例: 先着◯社/月）。希少性の演出にもなる |
| 法務 | 第三者サイトのクローリング、APIデータの再配布可否、特定電子メール法 | robots.txt遵守・低頻度、データ提供元の規約確認、同意取得（仕様書参照） |

## 4. 進め方（推奨）

| Phase | 期間 | 内容 | 判定基準 |
|---|---|---|---|
| **0. 手動検証** | 2〜3週間 | 既存ツール＋スプレッドシートで**10〜20件を手作り**。知人企業・既存リード・問い合わせ済み見込み客に送る | 有効申込→面談化 **20%以上**なら Phase 1へ。未満ならレポート内容を見直す |
| **1. MVP（半自動）** | 4〜6週間 | 解析パイプライン自動化＋**人のQA**（1営業日納品）。Webビューワー＋PDF | 面談化率・受注率を20件単位で計測 |
| **2. 自動化・拡張** | 以降 | QA省略（信頼度スコアが高いものだけ自動送付）、即時プレビュー、AI検索露出、GSC連携精密版 | CPA・受注単価 |

**Phase 0 を推す理由**: 施策の成否を決めるのは「レポートを見た人が面談に来るか」であり、パイプラインの出来ではない。手作りで「どのページが刺さったか」を架電で聞けば、自動化すべき範囲が確定する。

## 5. 確認したいこと（意思決定に必要）

1. **ターゲットの比率**: 想定リードは A（運用中）／B（停滞）／C（未開設）のどれが多いか？ → レポートの主モードが変わる
2. **架電体制**: 月に何件架電・面談できるか？ → 受付上限と自動化の優先度が決まる
3. **kwlabの中身**: 既にDataForSEO等のAPIでランクインKW・検索Volを取得しているか？クラスタリングロジックはあるか？ → 再利用できれば開発期間が半減
4. **代理店からの申込**: 歓迎（パートナー化）か除外か？
5. **即時性**: 「1営業日後にメール」でよいか、「その場でサマリー表示＋詳細は後日」が要るか？（競合の即時ツールとの比較で離脱が出るなら後者）
