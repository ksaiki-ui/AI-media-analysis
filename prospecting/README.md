# ターゲットリストの作り方（アウトバウンド営業）

AIメディアくんのアウトバウンド営業（土肥さんの架電・問い合わせフォーム・LinkedIn）に使う
「更新が止まっている自社メディアを持つ BtoB 企業」のリストを作る手順です。
候補集めと計測・採点・文面づくりは Claude が回し、送る・電話するのは人が行います。

## 狙う会社（ICP）

- BtoB サービス業で、マーケ専任がいないか 1 人体制の会社（人材紹介・派遣／受託開発・SIer／研修・コンサル／BPO／中規模の士業法人）
- コラム・ブログなどの自社メディアを持ち、記事は 5 本以上
- 次の 3 パターンのどれかに当てはまる。どれが刺さるかは架電の結果（パターン別のアポ率）で決める
  - **低頻度で継続**: 書く意欲はあるがペースが上がらない →「ペースを上げる」訴求
  - **リライト遅れ**: 古い年号の記事や 2 年以上手つかずの記事が多い →「直す優先順位」訴求
  - **停止**: 更新が止まった →「再開」訴求
- 外す: 大手、ポータル、SaaS 企業、広告・採用支援・制作・SEO の会社（自分で書ける側か競合）、行政（`exclude_domains.txt` とタイトル・説明文の語で判定）、直近 90 日に 6 本以上更新している会社（書く体制がある）

2026-10-22 の最初の版は製造業（受託加工）と士業で作ったが、製造業を選んだ根拠が弱かったため BtoB サービス業に切り替えた。

## 流れ

| 段 | 何をするか | 誰が | 道具 |
|---|---|---|---|
| 1. 領域を決める | 業種と、その業種の顧客が検索しそうな悩みのキーワードを選ぶ | Claude（毎週の振り返りで人と見直す） | — |
| 2. 候補を集める | キーワードで検索し、ポータル・行政を除いた中小企業のサイトの URL を集める | Claude | Web 検索 → `seeds/YYYY-MM-DD.csv` |
| 3. 計測する | 各社のメディアの記事数・最後の公開日・直近 1 年の公開数・問い合わせ導線・「営業お断り」の表記を調べる | 自動 | `media_check.py` |
| 4. 採点・文面 | 3 パターン／除外／要手確認に分け、架電の一言目とフォーム文面を作る | 自動 | `build_list.py` → xlsx |
| 5. 人の確認 | 3 パターンの行を開いて、会社の規模・業種と一言目の事実を確かめる。送ってよい行だけ残す | 人（才木さん／FS） | xlsx のステータス列 |
| 6. 当てる | 架電（土肥さん）、フォーム送信、LinkedIn（手動のみ） | 人 | xlsx のステータス・接触日・結果メモ |
| 7. 振り返る | 週 1 回、パターン別・業種別のアポ率を見て、領域とキーワードと文面を直す | Claude と人 | xlsx の結果列 |

### 実行

```bash
# 2. で作った seeds（列: url, segment, source_keyword）を計測
python3 prospecting/media_check.py prospecting/seeds/2026-10-22.csv /tmp/measured.csv

# 採点してリストにする。3 つ目に既存のリストを渡すと、そこにあるドメインを除いて新しい分だけを出す
python3 prospecting/build_list.py /tmp/measured.csv target_list_2026-10-22.xlsx [前回までのリスト.xlsx]
```

依存は `requests`、`beautifulsoup4`、`lxml`、`openpyxl`。

## パターンの基準（上から順に当てはめる）

| パターン | 条件 |
|---|---|
| 停止 | 最終公開から 180 日以上（90〜179 日は「停滞気味」として優先度・中） |
| （除外） | 直近 90 日に 6 本以上の公開・更新（活発） |
| リライト遅れ | 「【2024年版】」など過ぎた年号の記事が 2 本以上、または記事 30 本以上で半分以上が 2 年以上手つかず |
| 低頻度で継続 | 最終公開が 90 日以内で、直近 1 年の公開・更新が 3〜36 本 |
| 優先度・高 | 問い合わせ導線あり、かつ記事 10 本以上（本数不明を含む） |
| 要手確認 | 接続できない・日付が取れない。人が開いて確かめる |

最後の公開日は RSS を優先し、無ければサイトマップの lastmod、それも無ければ一覧ページの日付から推定します。
サイトマップの lastmod は「更新日」のことがあり、全ページ同じ日付のこともあるため（その場合は捨てる）、
`日付の出どころ` 列を見て、一言目に使う前に人が確かめてください。

## 守ること

- **送る前に人が見る。** 自動で送信・架電はしない。xlsx のステータスを人が変えたものだけが接触済み
- **文面に入れる事実は計測した公開情報だけ**（記事数・最後の公開月）。推測の数字や評価を足さない
- **検索順位を約束しない。** フォーム文面にもその旨を書いている
- **配信停止の一文を必ず入れる。** 「不要」と返ってきた会社は `exclude_domains.txt` に足し、二度と当てない
- **「営業お断り」と書かれたフォームには送らない**（`フォーム送信` 列が「不可」。架電も原則控える）
- **LinkedIn は人が手で送る。** 自動化ツールは使わない（規約違反になるため）
- クロールは robots.txt に従い、1 ドメインに 1 秒 1 回・最大 30 リクエストまで。User-Agent で名乗る

## 量の目安

月 10 商談（アポ 11〜12 件）を目標にすると、接触からアポの率を 2% と仮置きして月 500〜600 件の接触が要ります。
最初はその半分（月 250〜300 件、3パターンで月 150 件前後の新規）から始め、実績のアポ率で量を決め直します。
1 回の検索で使える中小企業のサイトは 6〜9 件ほど、そのうち 3 パターンに残るのは 2 割前後なので、
週 100〜150 件の候補を計測に回すのが目安です。
